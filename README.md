# trainee-journey-python

Central repository for every practical in the Python track learning plan.

## Structure

- `practicals/` - one folder per practical, named after its topic
- `.github/` - pull request template
- `CONTRIBUTING.md` - the branch + PR workflow used for all work

## Workflow in one line

`main` is always stable. Every practical is done on its own branch and merged into `main` through a pull request.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full workflow.
